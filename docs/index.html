小树苗成长记 —— 隐私政策

生效日期：2026 年 8 月 25 日

版本：v1.0

联系方式：752676416@qq.com（或通过应用内「设置 → 意见反馈」）

1. 概述

欢迎使用「小树苗成长记」（以下简称「本应用」或「我们」）。本应用是一款纯本地离线运行的育儿记录工具，旨在帮助父母记录宝宝成长的点滴瞬间。我们高度重视您的隐私保护，承诺不收集、不上传、不共享任何个人信息到服务器。

本隐私政策详细说明了本应用如何处理您的数据。请在使用前仔细阅读。

2. 我们收集的信息

本应用不收集任何个人身份信息（PII）。所有数据均存储在您的设备本地，包括但不限于：

数据类型存储位置用途是否上传
------------
宝宝基本信息（姓名、生日、性别、头像）设备本地加密存储区分多宝宝、计算月龄、显示头像否
照片/视频文件设备相册/应用沙箱时光轴展示、里程碑记录否
文字日记/语音转文字设备本地数据库成长记录、搜索检索否
疫苗接种记录设备本地数据库接种提醒、状态追踪否
喂药提醒设置设备本地数据库本地通知调度否
应用偏好设置（主题、语言等）设备本地 Preferences个性化体验否

*关键承诺**：以上所有数据**从未离开您的手机**。我们没有服务器，没有后端数据库，没有任何数据上传通道。

3. 权限使用说明

本应用仅申请以下最小必要权限，均用于核心功能实现：

权限系统标识使用场景用户可拒绝
------------
相机`ohos.permission.CAMERA`拍照记录成长瞬间、扫描二维码是（拒绝后可从相册选择）
相册读写`ohos.permission.READ_MEDIA` / `ohos.permission.WRITE_MEDIA`选择照片/视频、保存生成的纪念图是
通知`ohos.permission.NOTIFICATION`疫苗接种提醒、喂药提醒是（拒绝后不接收提醒）
精确闹钟`ohos.permission.SCHEDULE_EXACT_ALARM`定时触发喂药/疫苗通知是（拒绝后提醒可能延迟）
震动`ohos.permission.VIBRATE`通知到达时震动反馈是

*权限最小化原则**：拒绝任意权限不影响应用核心记录功能，仅对应功能受限。

4. 本地通知机制

- 疫苗提醒：根据国家免疫规划 + 宝宝出生日期，本地计算下次接种时间，仅在设备上调度系统通知。

- 喂药提醒：用户手动添加的用药计划，仅在设备上按时触发通知。

- 通知内容：仅包含宝宝昵称、提醒类型、时间，不含任何医疗诊断信息。

- 用户控制：随时在「设置 → 通知管理」开关/删除单条提醒；系统层面可在「设置 → 通知」关闭应用所有通知。

5. 数据安全

措施说明
------
**本地加密存储**敏感字段（宝宝姓名、生日）使用 HarmonyOS `EncryptedPreferences` 加密持久化
**沙箱隔离**应用数据仅本进程可访问，其他应用无法读取
**无网络通信**应用**未申请网络权限**（`ohos.permission.INTERNET`），物理层面杜绝数据外传
**导出加密**支持导出加密备份文件（AES-256，用户自设密码），导入时校验完整性

6. 用户权利

您对自己的数据拥有完全控制权：

权利实现方式
------
**访问/查看**应用内「时光轴/知识库/档案」随时查看所有记录
**修正/更新**长按任意记录可编辑/删除；宝宝信息可在「档案」修改
**删除**单条删除、批量清空、或卸载应用彻底清除所有数据
**导出/迁移**「设置 → 数据导出」生成加密备份，可导入新设备/新版本
**注销账户**本应用无账户体系，**卸载即注销**，无残留数据

7. 儿童隐私保护

本应用面向父母/监护人使用，记录对象为未成年子女。我们：

- 不直接向儿童收集信息

- 不包含广告、推荐算法、用户画像

- 不与第三方共享儿童数据

- 建议监护人定期检查并管理记录内容

8. 第三方 SDK / 服务

本应用未集成任何第三方 SDK（统计、推送、广告、崩溃上报、地图、支付等）。所有功能均基于 HarmonyOS 系统 API 自研实现。

9. 数据留存与销毁

- 数据永久保存在您的设备上，除非您主动删除或卸载应用。

- 卸载应用时，系统会自动清理应用沙箱内所有数据（含数据库、Preferences、缓存）。

- 相册中通过应用保存的照片/视频不随应用卸载而删除，归您永久所有。
