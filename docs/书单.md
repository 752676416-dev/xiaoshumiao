## 🎯 采购优先级建议

1. **首选补 2 本**：**《美国儿科学会育儿百科》**（百科模块）+ **《诸福棠实用儿科学》**（常见病模块）——撑起 App 专业性

## 📌 选书与处理提醒

- 优先买纸质/正版电子（微信读书、京东读书、华为阅读均有）
- 扫描版大部头（如诸福棠 3000+ 页）识读工作量大，先精读章节
- 科普向（育儿百科）可全文识读；专业大部头按需精读
- 已确立的处理管线（devpsych 案例）：PDF 渲染 → RapidOCR → 条目构建 → 联网核对 → 合并入库
- 合规红线：所有用药/医学内容只做科普展示，不推荐不计算剂量
